## プロジェクト概要

本プロジェクトは、小児科学、新生児医学、小児の発育と発達、感染症の予防と制御、遺伝代謝疾患の診断と治療、救急・重症ケアなどの中核領域を体系的に統合し、**184の主要臨床スキル**を**15の大分類**にまとめています。

**対象読者**: 小児科医、医学生、新生児科医療チーム、公衆衛生従事者、研修医

**参考教科書**: 人民衛生出版社『小児科学』第10版

**⚠️リスク⚠️**: 高リスクの臨床治療、手技、投薬ガイダンスは、一般的な無監視環境でのインストールや使用には適さない可能性があります。

**対策**: 資格のある小児科医、新生児科医、小児集中治療医、または監督下での医学教育環境に限定し、出力を扱う前に臨床医によるレビューを必須とします。

**⚠️リスク⚠️**: ガイダンスが現在の地域ガイドライン、施設プロトコル、または患者固有の禁忌と矛盾する可能性があります。

**対策**: 使用前に、計画、手順、閾値、フォローアップ計画が地域の最新基準および施設の方針に準拠していることを確認してください。

**⚠️リスク⚠️**: 緊急侵襲的手技、新生児蘇生、小児投薬量計算、および感受性の高い発達・行動に関する話題は、軽率に扱うと患者の安全やプライバシーに危害を及ぼす可能性があります。

**対策**: これらのシナリオに明示的な警告を追加し、緊急時は救急・ICUケアに誘導し、適切な臨床または監督下での教育ニーズを持つユーザーにアクセスを制限します。

### 質問戦略

#### 1. **概念**

質問:
```bash
新生児生理的黄疸の概念
```

回答:
```bash
## 新生児生理的黄疸の概念
**新生児生理的黄疸**とは、ビリルビン代謝の特性により新生児期に一過性に血清非抱合型ビリルビンが上昇する状態であり、通常は特別な介入を必要とせず自然に消退する良性の経過をたどります。
### 診断基準
| パラメータ | 正期産児 | 早産児 |
|-----------|---------|--------|
| 出現時期 | 生後2～3日 | 生後3～5日 |
| ピーク時期 | 生後4～5日 | 生後5～7日 |
| 消退時期 | 生後5～7日 | 生後7～9日 |
| 血清ビリルビン最大値 | < 221 μmol/L (12.9 mg/dL) | < 256 μmol/L (15 mg/dL) |
| 1日あたりの上昇幅 | < 85 μmol/L (5 mg/dL) | < 85 μmol/L (5 mg/dL) |
### 主要な鑑別
- **生理的黄疸**: 上記の時間枠と閾値に合致し、全身状態は良好
- **病的黄疸**: 出現が早すぎる（<24h）、程度が重すぎる、遷延する、1日あたりの上昇が速すぎる、または直接ビリルビンが上昇
- **母乳性黄疸**: 生後1週で出現、2～3週でピークに達し、母乳を3日間中止すると有意に低下
### 管理原則
特別な治療は不要。十分な哺乳を確保し胎便排泄を促進する。TSBが介入閾値に近づいた場合は光線療法の評価を開始する。
```

#### 2. **臨床ケース分析**

質問:
```bash
新生児、在胎週数38週、経腟分娩、出生体重3.2kg。生後24時間以内に皮膚黄染が出現し、急速に増悪。生後36時間でTSB 15mg/dL、非抱合型ビリルビン優位。母親の血液型O型Rh(+)、児の血液型A型Rh(+)。最も可能性の高い診断は？
```

回答:
```bash
## 症例分析
**最も可能性の高い診断：ABO血液型不適合による新生児溶血性疾患**
### 診断根拠
| 臨床的特徴 | 示唆する所見 |
|-----------|------------|
| **生後24時間以内の黄疸出現** | 病的黄疸 — 出現時期が早すぎる |
| **血清総ビリルビン15mg/dL（257μmol/L）** | 生理的範囲を有意に超過（正常ピーク<12.9mg/dL） |
| **非抱合型ビリルビン優位** | 溶血性黄疸に一致 |
| **母親O型 + 児A型** | ABO不適合の最も一般的な組み合わせ（母体抗A IgGが胎盤通過） |
| **Coombs試験陽性** | 免疫介在性溶血の直接証拠 |
### その後の管理
1. **直ちに光線療法を開始** — 高強度青色光（425～475nm）
2. **TSBをq4～6hでモニタリング** — 交換輸血の要否評価
3. **血算＋網赤血球数検査** — 貧血の程度評価
4. **IVIG投与** — 0.5～1g/kg、溶血をブロック
5. **交換輸血の適応評価** — TSBが交換輸血閾値以上、または光線療法が無効な場合
```

#### 3. **試験問題**

質問:
```bash
乳児、8か月、3日間の発熱後、解熱してから発疹が出現。最も可能性の高い診断は：
A. 麻疹
B. 風疹
C. 突発性発疹（Exanthem subitum）
D. 猩紅熱
E. 水痘
```

回答:
```bash
**答え：C. 突発性発疹（Exanthem subitum）**
### 鑑別診断
| 疾患 | 発熱と発疹の関係 | 発疹の特徴 | その他の特徴 |
|------|----------------|-----------|------------|
| A. 麻疹 | 発熱**と同時に**発疹（熱盛疹出） | 暗紅色斑丘疹、耳後部・生え際→顔面→体幹→四肢 | Koplik斑、カタル症状 |
| B. 風疹 | 発熱**と同時に**発疹 | 淡紅色斑丘疹、顔面から→急速に全身へ | 耳後部・後頭部リンパ節腫脹 |
| **✅ C. 突発性発疹** | **解熱後に発疹** | ばら色斑丘疹、体幹→顔面→四肢、1～2日で消退 | 高熱（39～40℃）、全身状態良好 |
| D. 猩紅熱 | 発熱**と同時に**発疹 | 粟粒大の充血性発疹、皮膚皺襞部にパスティア線 | 苺舌、咽頭炎 |
| E. 水痘 | 発熱**と同時に**発疹 | 求心性分布：斑→丘→水疱→痂皮の「四世同堂」 | 強い掻痒感 |
### なぜ C か？
問題文のキーとなる手がかり：
- **8か月** → 突発性発疹は6～18か月の乳児に最も多い
- **3日間の発熱後、解熱して発疹出現** → **「熱退疹出」は突発性発疹の古典的特徴**であり、他の発疹性疾患の「熱盛疹出」と明確に区別される
- ばら色斑丘疹、体幹から始まる → 突発性発疹の発疹順序に一致
### 管理の要点
自然軽快する疾患であり、特異的な抗ウイルス治療は不要。対症療法が中心：
- 高熱のコントロール（物理的冷却、解熱剤）
- 十分な水分摂取の確保
- 熱性けいれんに注意
```
