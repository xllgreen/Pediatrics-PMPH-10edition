## О проекте

Этот проект систематически объединяет ключевые области педиатрии, включая неонатологию, рост и развитие ребенка, профилактику и контроль инфекционных заболеваний, диагностику и лечение генетических и метаболических заболеваний, а также неотложную и интенсивную терапию. Он охватывает **184 ключевых клинических навыка**, организованных в **15 категорий**.

**Целевая аудитория**: Педиатры, Студенты-медики, Специалисты общественного здравоохранения, Команды неонатальной помощи

**Учебник**: «Педиатрия» (Народное медицинское издательство, 10-е издание)

## Быстрый старт

### Установка

CLI:
```bash
openclaw skills install pediatrics-pmph-10edition
```

### Использование

Каждый навык состоит из четырех разделов:
1. **Когда использовать** — Клинические сценарии для применения навыка
2. **Шаги выполнения** — Стандартизированная процедура
3. **Предостережения** — Противопоказания и предупреждения
4. **Ссылки** — Дополнительные материалы

**Примеры:**
- «На основе навыка 'Диагностика и стратифицированное лечение неонатальной гипогликемии' разработайте план ведения доношенного новорожденного возрастом 4 часа с уровнем глюкозы крови 1,8 ммоль/л.»
- «Используя навык 'Диагностика и классификация нефротического синдрома', проанализируйте диагностические шаги для 5-летнего мальчика с массивной протеинурией, гипоальбуминемией и отеками.»
- «Ссылаясь на навыки 'Национальный календарь прививок' и 'Обязательные вакцины до 12 месяцев', составьте полный план вакцинации на 0–12 месяцев для здорового 2-месячного младенца.»
