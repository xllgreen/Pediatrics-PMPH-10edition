## О проекте

Данный проект систематически объединяет основные области педиатрии, неонатологии, роста и развития ребёнка, профилактики и контроля инфекционных заболеваний, диагностики и лечения наследственных нарушений обмена веществ, а также неотложной и реанимационной помощи. Он охватывает **184 ключевых клинических навыка**, разделённых на **15 основных категорий**.

**Целевая аудитория:** Педиатры, студенты-медики, неонатальные медицинские бригады, работники общественного здравоохранения, ординаторы

**Справочный учебник:** «Педиатрия», 10-е издание, Народное медицинское издательство (PMPH)

**⚠️Риск⚠️:** Клинические методы лечения, процедуры и рекомендации по дозировке высокого риска могут не подходить для общего использования без наблюдения.

**Снижение риска:** Предназначен только для квалифицированных педиатров, неонатологов, детских реаниматологов или контролируемых образовательных медицинских сред; требуется проверка клиницистом перед применением результатов.

**⚠️Риск⚠️:** Рекомендации могут противоречить текущим местным руководствам, больничным протоколам или специфическим противопоказаниям пациента.

**Снижение риска:** Перед использованием убедитесь, что все планы, процедуры, пороговые значения и планы последующего наблюдения соответствуют местным стандартам и политике учреждения.

**⚠️Риск⚠️:** Неотложные инвазивные процедуры, реанимация новорождённых, расчёт педиатрических доз препаратов и чувствительные темы развития и поведения могут нанести вред безопасности или конфиденциальности пациента при небрежном обращении.

**Снижение риска:** Добавьте явные предупреждения для этих сценариев, направляйте неотложные случаи в отделения неотложной помощи/ОИТ и ограничьте доступ квалифицированным клиницистам или пользователям с контролируемыми образовательными потребностями.

### Стратегии вопросов

#### 1. **Концепция**

Вопрос:
```bash
Понятие физиологической желтухи новорождённых
```

Ответ:
```bash
## Понятие физиологической желтухи новорождённых
**Физиологическая желтуха новорождённых** — это транзиторное повышение уровня неконъюгированного билирубина в сыворотке крови новорождённых, обусловленное особенностями метаболизма билирубина; это доброкачественный процесс, который обычно проходит без специфического вмешательства.
### Диагностические критерии
| Параметр | Доношенный | Недоношенный |
|----------|-----------|-------------|
| Появление | 2–3 день после рождения | 3–5 день после рождения |
| Пик | 4–5 день после рождения | 5–7 день после рождения |
| Исчезновение | 5–7 день после рождения | 7–9 день после рождения |
| Максимальный билирубин сыворотки | < 221 мкмоль/л (12,9 мг/дл) | < 256 мкмоль/л (15 мг/дл) |
| Суточный прирост | < 85 мкмоль/л (5 мг/дл) | < 85 мкмоль/л (5 мг/дл) |
### Ключевая дифференциальная диагностика
- **Физиологическая желтуха**: Соответствует вышеуказанным срокам и порогам; общее состояние хорошее
- **Патологическая желтуха**: Появление слишком раннее (<24 ч), степень слишком высокая, длительное течение, чрезмерный суточный прирост или повышение прямого билирубина
- **Желтуха грудного вскармливания**: Появление на 1-й неделе, пик на 2–3-й неделе, значительное снижение при отмене грудного вскармливания на 3 дня
### Принципы ведения
Специфического лечения не требуется; обеспечьте достаточное кормление для стимуляции отхождения мекония. При приближении ОБС к порогу вмешательства начните оценку необходимости фототерапии.
```

#### 2. **Клинический разбор случая**

Вопрос:
```bash
Новорождённый, срок гестации 38 недель, вагинальные роды, масса тела при рождении 3,2 кг. В течение 24 часов после рождения появилась желтушность кожи, быстро нарастающая. В возрасте 36 часов ОБС 15 мг/дл, преимущественно за счёт неконъюгированного билирубина. Группа крови матери: O Rh(+); группа крови ребёнка: A Rh(+). Каков наиболее вероятный диагноз?
```

Ответ:
```bash
## Анализ случая
**Наиболее вероятный диагноз: Гемолитическая болезнь новорождённых вследствие ABO-несовместимости**
### Диагностическое обоснование
| Клиническая особенность | Указание |
|------------------------|----------|
| **Желтуха в течение 24 ч после рождения** | Патологическая желтуха — слишком раннее появление |
| **Общий билирубин сыворотки 15 мг/дл (257 мкмоль/л)** | Значительно выше физиологической нормы (нормальный пик <12,9 мг/дл) |
| **Преимущественно неконъюгированный билирубин** | Соответствует гемолитической желтухе |
| **Мать O + ребёнок A** | Наиболее частая комбинация ABO-несовместимости (материнские анти-A IgG проникают через плаценту) |
| **Положительная проба Кумбса** | Прямое доказательство иммуноопосредованного гемолиза |
### Последующее ведение
1. **Немедленно начать фототерапию** — Интенсивный синий свет (425–475 нм)
2. **Мониторинг ОБС каждые 4–6 ч** — Оценка необходимости заменного переливания крови
3. **ОАК + ретикулоциты** — Оценка степени анемии
4. **В/в введение иммуноглобулина (ВВИГ)** — 0,5–1 г/кг для блокады гемолиза
5. **Оценка показаний к заменному переливанию крови** — Если ОБС ≥ порога заменного переливания или фототерапия неэффективна
```

#### 3. **Экзаменационные вопросы**

Вопрос:
```bash
Ребёнок 8 месяцев, лихорадка в течение 3 дней; сыпь появляется после снижения температуры. Наиболее вероятный диагноз:
A. Корь
B. Краснуха
C. Розеола детская (внезапная экзантема)
D. Скарлатина
E. Ветряная оспа
```

Ответ:
```bash
**Ответ: C. Розеола детская (внезапная экзантема)**
### Дифференциальный диагноз
| Заболевание | Связь лихорадки и сыпи | Характеристики сыпи | Другие признаки |
|------------|------------------------|--------------------|-----------------|
| A. Корь | Лихорадка **с** сыпью | Тёмно-красная макулопапулёзная сыпь, от заушной области → лицо → туловище → конечности | Пятна Коплика, катаральные явления |
| B. Краснуха | Лихорадка **с** сыпью | Бледно-розовая макулопапулёзная сыпь, сначала на лице → быстрое распространение на всё тело | Затылочная/заднешейная лимфаденопатия |
| **✅ C. Розеола детская** | **Сыпь после снижения температуры** | Розовая макулопапулёзная сыпь, туловище → лицо → конечности, исчезает за 1–2 дня | Высокая лихорадка (39–40°C), общее состояние хорошее |
| D. Скарлатина | Лихорадка **с** сыпью | Мелкоточечная гиперемическая сыпь, линии Пастиа в складках кожи | «Малиновый» язык, фарингит |
| E. Ветряная оспа | Лихорадка **с** сыпью | Центростремительное распределение: пятна → папулы → везикулы → корочки | Интенсивный зуд |
### Почему C?
Ключевые подсказки в вопросе:
- **8 месяцев** → Розеола наиболее распространена у детей 6–18 месяцев
- **Лихорадка 3 дня, сыпь после снижения температуры** → **«Сыпь после снижения температуры» — классический признак розеолы**, резко контрастирующий с «сыпью на фоне лихорадки» при других экзантематозных заболеваниях
- Розовая макулопапулёзная сыпь, начинающаяся с туловища → соответствует последовательности высыпаний при розеоле
### Основные моменты ведения
Самоограничивающееся заболевание; специфическое противовирусное лечение не требуется. Основное внимание — поддерживающая терапия:
- Контроль высокой температуры (физическое охлаждение, жаропонижающие)
- Обеспечение достаточного потребления жидкости
- Наблюдение за фебрильными судорогами
```
